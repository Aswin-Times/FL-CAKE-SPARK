# Component Guidelines

## Component Library Organization

Atomic design components are stored in `frontend/src/components/`:

- `ui/`: Primitives such as Button, Input, Modal, Badge, Card, Spinner.
- `layout/`: App Shell, Header, Footer, Container, Sidebar.
- `navigation/`: Navbar, Breadcrumbs, Pagination, MobileNav.
- `feedback/`: Toast alerts, ConfirmDialog, Skeleton loaders.

Feature components reside in `frontend/src/features/<feature-name>/components/`.
