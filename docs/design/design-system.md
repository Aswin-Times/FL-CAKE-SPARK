# Design System

## Overview

CAKE SPARK uses a warm, premium, appetizing aesthetic designed for pastry shops and celebratory confections.

## Principles

1. **Appetizing & Welcoming**: Warm tones, gentle shadows, and tactile cards highlighting baked creations.
2. **Accessible & Responsive**: High-contrast typography, screen reader accessible navigation, and fluid layouts for mobile ordering.
3. **Consistent Component Tokens**: Atomic reusable UI elements defined in Tailwind CSS and structured under `components/ui/`.
