# Typography

## Font Families

- **Display / Headers**: `Playfair Display`, serif — provides handcrafted artisan bakery charm.
- **Body / Interface**: `Inter`, sans-serif — optimal readability across desktop and mobile screens.
- **Monospace / Order Codes**: `JetBrains Mono` or system mono for order tracking numbers and receipts.

## Hierarchy

- **Heading 1**: 2.5rem (40px) / Bold / 1.2 line height
- **Heading 2**: 2rem (32px) / SemiBold / 1.25 line height
- **Heading 3**: 1.5rem (24px) / Medium / 1.3 line height
- **Body Large**: 1.125rem (18px) / Regular / 1.5 line height
- **Body Regular**: 1rem (16px) / Regular / 1.5 line height
- **Caption / Small**: 0.875rem (14px) / Regular / 1.4 line height
