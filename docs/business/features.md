# Business Features

## Customer Features

- **Storefront**: Browse cakes by occasion, flavor, weight, dietary preference (eggless/vegan).
- **Product Details**: Multi-image view, flavor selection, cake message customization, delivery date picker.
- **Custom Cake Builder**: Guided multi-step inquiry form for custom celebration cakes.
- **Cart & Checkout**: Cart review, coupon application, address entry, Razorpay payment flow.
- **Order Tracking**: Real-time status tracker (Received, Baking, Decorated, Out for Delivery, Delivered).

## Admin Features

- **Order Dashboard**: Order status Kanban, filter by delivery date, order printing.
- **Catalog Management**: Add/edit cakes, price variants, manage stock availability.
- **Custom Cake Request Review**: Review customer submissions, approve quotes, schedule consultations.
- **Coupons & Promotions**: Manage promo codes and discounts.
